# HD-003 Account Lockout Policy Validation

## Ticket Information  

|Field | Value |
|-------|-------|
| Ticket ID | HD-003 |
| Date | August 2, 2026 |
| Priority | Medium |
| Status | Investigation |
| Category | Group Policy |

## Objective

Validate that the configured Account Lockout Policy locks a user account after five failed sign in attempts.

## Expected Result

The user account should lock after five consecutive failed password attempts.

## Actual Result

The account did not lock after repeated failed sign in attempts.
